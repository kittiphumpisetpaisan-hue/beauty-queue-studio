# 💇‍♀️ Beauty Queue Studio — ระบบจองคิวร้านเสริมสวย

ระบบจองคิวร้านเสริมสวยออนไลน์แบบครบวงจร สำหรับร้านเสริมสวยขนาดเล็กถึงกลาง

---

## คำอธิบายโปรเจกต์

เว็บไซต์นี้แบ่งออกเป็น 2 ฝั่ง:

- **ฝั่งลูกค้า**: จองคิวบริการ ดูสถานะคิว ตรวจสอบการจอง
- **ฝั่งแอดมิน**: จัดการคิว บริการ และตั้งค่าร้าน

---

## Tech Stack

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- **Prisma ORM** + SQLite
- **React Hook Form** + **Zod**
- **date-fns** สำหรับจัดการวันเวลา

---

## วิธีติดตั้ง

```bash
# 1. ติดตั้ง dependencies
npm install

# 2. สร้างไฟล์ .env (ถ้ายังไม่มี)
# DATABASE_URL="file:./dev.db"
```

---

## วิธี migrate database

```bash
npx prisma migrate dev --name init
```

---

## วิธี seed ข้อมูล

```bash
npx prisma db seed
```

ระบบจะสร้างข้อมูลตัวอย่าง:
- บริการ 6 รายการ (ตัดผม, สระไดร์, ทำสี, ทรีตเมนต์, ทำเล็บ, แต่งหน้า)
- ตั้งค่าร้าน Beauty Queue Studio เปิด 10:00–20:00 น. หยุดวันจันทร์

---

## วิธีรันระบบ

```bash
npm run dev
```

เปิดเบราว์เซอร์ไปที่ [http://localhost:3000](http://localhost:3000)

## วิธีใช้งานฝั่งลูกค้า

1. เข้าหน้าแรก → กด **"จองคิวเลย"**
2. เลือกบริการที่ต้องการ
3. เลือกวันที่และเวลา (ระบบแสดงเฉพาะช่วงว่าง)
4. กรอกชื่อและเบอร์โทร
5. ตรวจสอบข้อมูลแล้วกด **"ยืนยันการจอง"**
6. รับ **หมายเลขการจอง** (เช่น BK-20260607-0001)
7. ตรวจสอบสถานะที่หน้า **"ตรวจสอบคิว"**

---

## วิธีใช้งานฝั่งแอดมิน

เข้าที่ [http://localhost:3000/admin](http://localhost:3000/admin)

- **แดชบอร์ด**: ดูสรุปคิวและรายได้วันนี้
- **จัดการคิว**: ดูรายการจอง กรองตามวันและสถานะ เปลี่ยนสถานะคิว
- **จัดการบริการ**: เพิ่ม/แก้ไขบริการ ปิดบริการชั่วคราว
- **ตั้งค่าร้าน**: แก้ไขชื่อร้าน เวลาเปิด วันหยุด
